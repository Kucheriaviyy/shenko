SHENKO site: куда что класть
============================
index.html            сайт (его открывают посетители)
editor.html           конструктор (открывать по адресу сайта: твойник.github.io/shenko/editor.html, не двойным кликом)
content.json          весь контент сайта; его пишет конструктор, руками не нужно

assets/img/           картинки (WebP/PNG/JPG). Конструктор сам кладёт сюда загруженные фото
assets/models/        3D-модели .glb (до 5 МБ, текстуры 1024-2048 px, Draco)
assets/pdf/           PDF и картинки страниц для PDF-книги (страница 1.webp, 2.webp...)
assets/transitions/   SVG-переходы между секциями. Новый файл: положи сюда
                      и впиши его имя в конструкторе: Настройки, поле "Переходы"
assets/fonts/         шрифты .woff2 и License.txt
assets/css/site.css   стили сайта
assets/js/site.js     отрисовка сайта из content.json
assets/js/editor.js   код конструктора

Как работает Push: картинки и .glb из конструктора загружаются в нужные папки,
затем обновляется content.json. Сайт обновляется через 1-2 минуты.
Локально: python -m http.server в этой папке, затем localhost:8000/editor.html

Типы секций: Обычная, Хедер (на весь экран, статичный, остальные наезжают), Содержание
(строится само из групп и названий секций), Футер (ссылки Privacy/Terms добавляются сами).
Группа секции = заголовок в содержании, название секции = якорная ссылка.

Новое в этой версии
assets/img/header.webp, about-yehor.webp, about-bbzw.webp   картинки хедера и раздела Who am I
assets/img/qr.svg                                           QR-код, который видят на компьютере
assets/pdf/flottefjell/p01..p16.webp                        страницы брошюры для листалки (обложка, развороты, задняя сторона)
Своя брошюра: положи страницы в assets/pdf/<папка>/ и впиши пути в блок "PDF-книга".
Быстрый просмотр сайта на компьютере без QR: добавь к адресу ?full
Стрелки на клавиатуре: сдвиг выбранного блока на 1px, Shift = 10px, Alt = на одну ячейку сетки.
Высота секции: потяни за нижний край секции в превью.
